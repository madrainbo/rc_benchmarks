rc_engine · inference benchmarks

Same model, same machine, measured side by side

rc_engine is a Rust inference engine for Mixture-of-Experts language models, running on NVIDIA GPUs and Apple Silicon. These are its measured results against llama.cpp and Ollama, with the same model file on the same hardware, and the places where it is still behind.

Other models (RTX 5080)

Single-stream decode, 128-token prompt and 256 generated tokens, against llama.cpp with the same GGUF file. Measured in November (Nemotron in October, with a newer llama.cpp build that supports it).

Where rc_engine is behind

How these were measured. Each engine loads the same GGUF file with the same context size and serves the same prompts through its own HTTP API. Greedy sampling, thinking off. The engines take turns, loaded alternately within one session; warm-up requests are discarded and the median is reported. Times are each server's own measurement. llama.cpp 7d56da7, Ollama 0.40.17 with its MLX model. rc_engine's source is private and available on request.
